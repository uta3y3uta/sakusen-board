# 作戦ボード

教育現場で使える，シンプルで直感的な作戦ボードアプリです。
ブラウザだけで動き，インストール不要。GitHub Pagesで公開して，URLで誰にでも共有できます。

## できること

### 名簿の取り込み
- **コピペ**（タブ・カンマ・スペース区切り対応）
- **Excelファイル**（.xlsx / .xls / .csv）
- **Googleスプレッドシート**（公開CSV URL）

1列目が数字なら自動で「背番号」として取り込みます。

### カードのカスタマイズ
- 文字色・カードの色を **一括／個別** に変更
- **自チーム／相手チーム** の切替
- **空白カード**（名前なし）でもボード上に置ける
- **「その他」欄**：キャプテン・副キャプテン等のポジション名や自由メモ
- **「番号」チェックボックス**：チェックを入れるとカードに背番号が表示される

### 10種類のボードデザイン

1. フリー（白板・グリッド付き）
2. 校庭
3. 体育館
4. 教室
5. ゴール型1（サッカー）
6. ゴール型2（バスケットボール）
7. ゴール型3（ラグビー・フラッグフットボール）
8. ベースボール型（ベースボール）
9. ネット型（バレーボール）
10. ドッジボール

背景はすべて白。コートのラインは淡いブルーグレーで控えめに描かれ，名前カードや図形が前面で目立つようになっています。

### 直感的な操作
- カードを **ドラッグ＆ドロップ** で自由に配置（PC・タブレット両対応）
- **ダブルクリック**でカードを編集

### ホワイトボードマーカー機能
- ボード上に **直接書き込み** ができます
- ペン色・太さを自由に変更
- 消しゴム・一筆戻す・全消去
- 描画も保存・共有されます

### ボード上の便利ボタン
- **JSON保存**：現在のボード状態をファイルに保存
- **JSON読込**：保存したファイルから復元
- **JPEG保存**：ボードの見た目をそのまま画像で保存
- **公開URLの共有**：ボードの状態を含むURLを発行（受け取った人がブラウザで開くだけで再現）

## 使い方

1. ブラウザで `index.html` を開く（GitHub Pages公開後は公開URLを開く）
2. 右上「取込」から名簿を読み込む
3. デザインを選び，「全員をボードへ」または個別にドラッグして配置
4. 必要に応じて描画・色変更
5. 「公開URLの共有」または「JPEG保存」で配布

## GitHub Pagesでの公開

このリポジトリは GitHub Pages で公開されています。
ローカルで動かす場合は，3ファイル（`index.html` / `styles.css` / `app.js`）を同じフォルダに置いてブラウザで開くだけです。

### 自分のリポジトリで公開する手順

```bash
git clone <このリポジトリのURL>
cd sakusen-board
# 自分のリポジトリへ push
gh repo create <your-name>/sakusen-board --public --source=. --push
# GitHub Pages を有効化
gh api -X POST repos/<your-name>/sakusen-board/pages -f source[branch]=main -f source[path]=/
```

## データの保存

- 通常はブラウザ内（localStorage）に自動保存されます
- 別のPCに移したい場合や，バックアップを残したい場合は **JSON保存** を使ってください
- 完全消去は「全消去」ボタンか，ブラウザの履歴データ削除で
